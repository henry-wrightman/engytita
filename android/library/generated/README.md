# Generated UniFFI bindings (Kotlin)

`org/engytita/engytita_ffi.kt` is produced by UniFFI from `engytita-ffi`.
Do not edit by hand - regenerate with:

```bash
./scripts/generate-bindings.sh
```

Platform Android wiring (BLE/UWB, packaging) belongs in
[`../`](../) - scaffold only; not implemented as a buildable module yet.
